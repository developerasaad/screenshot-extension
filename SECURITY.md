# Security Policy

We take the security and privacy of **ScreenShot — Full Page Capture** seriously.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public GitHub issue**.

Instead, please submit your report via **[GitHub Security Advisories](https://github.com/developerasaad/screenshot-extension/security/advisories/new)**.

### What to Include in Your Report

Please provide as much detail as possible to help us reproduce and fix the issue quickly:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- The specific operating system and browser versions tested.
- Any suggested fixes or mitigations.

---

## Disclosure Policy

We ask that you give maintainers reasonable time to investigate and address the vulnerability before disclosing it publicly. We will:
1. Acknowledge receipt of your vulnerability report within 48 hours.
2. Provide an estimated timeline for investigation and resolution.
3. Notify you once a fix has been developed and published in a release.

Thank you for helping keep this project safe for everyone.
